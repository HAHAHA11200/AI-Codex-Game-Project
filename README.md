# Moon Lantern

A lightweight browser RPG with:

- a longer chapter-based story
- turn-based monster fights
- XP, leveling, and stat growth
- relics and loot that grant passive buffs
- a Traveler Menu with armor loadouts, separate loot sections, and a light skill tree
- ability unlocks tied to major items
- inline scene visuals for key locations and bosses
- browser autosave through `localStorage`

## Run it

Open `/Users/haklilu/Documents/moon-lantern-adventure/index.html` in a browser.

If you want to serve it locally instead:

```bash
cd /Users/haklilu/Documents/moon-lantern-adventure
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
